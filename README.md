# 📺 Clone YouTube

Projeto desenvolvido como revisão prática dos conceitos de HTML e CSS aprendidos até aqui.

## 💡 Sobre

A ideia foi recriar a interface do YouTube do zero, sem frameworks ou JavaScript,
aplicando na prática os fundamentos do desenvolvimento front-end.

## 🛠️ Tecnologias

- HTML5
- CSS3

## 📚 Conceitos praticados

- CSS Grid para o layout principal (header, sidebar e main)
- Flexbox para alinhamento de componentes
- Grid responsivo com `repeat(auto-fill, minmax())` nos cards
- Variáveis CSS para controle de cores e tema escuro
- Semântica HTML com `<header>`, `<aside>`, `<main>`, `<article>`
- `object-fit` e `aspect-ratio` para imagens responsivas
